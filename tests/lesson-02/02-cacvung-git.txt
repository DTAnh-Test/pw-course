2. Trong một folder mới được tạo ra, mình thực hiện lần lượt các lệnh sau. Hãy liệt kê các
file theo từng vùng sau khi thao tác một loạt các lệnh sau:
a. Tạo 3 file: file1, file2, file3 => Khởi tạo 3 file tại vùng Local
b. Chạy lệnh: git init => Thực hiện khởi tạo một repo local tại thư mục đang đứng. Lúc này 3 file (file1, file2, file3) sẽ được chuyển vào vùng Working directiry
c. Chạy lệnh: git commit -m”init project”: Có thể báo lỗi hoặc một cảnh báo nào đó do lúc này vùng Staging đang trống
d. Chạy lệnh: git add file1 => Báo lỗi do không tồn tại file1
e. Chạy lệnh: git commit -m”add file1”: Có thể báo lỗi hoặc một cảnh báo nào đó do lúc này vùng Staging đang trống
f. Chạy lệnh: git commit -m”add file”: Có thể báo lỗi hoặc một cảnh báo nào đó do lúc này vùng Staging đang trống
-----
=> câu c, e, f: Sau khi chạy thử thực tế thì có thông báo là không có gì để commit cả, đồng thời đưa ra các file có sự thay đổi/ tạo mới kèm hướng dẫn sử dụng lệnh git add để tạo commit
