1. Giải thích các câu lệnh: git init, git add <file_name>, git add ., git commit -m “message”.

- git init: Khi chạy lệnh này sẽ thực hiện khởi tạo ra 3 vùng:
    + Working directiry: Chứa các file mới được tạo hoặc các file có sự thay đổi
    + Staging Area: Chứa các file chuẩn bị commit (tạo ra các phiên bản)
    + Repository: Chứa các commit (phiên bản)
- git add <file_name>: Đẩy các file được gọi tên ở vùng Working directiry vào vùng Staging Area
- git add.: Đẩy tất cả các file ở vùng Working directiry vào vùng Staging Area
- git commit -m “message”: Gom các file muốn commit vào 1 phiên bản với mô tả ngắn về phiên bản (message)
